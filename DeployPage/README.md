# NORQUE STUDIOS™ Website

A faithful, pixel-perfect rebuild of the **NORQUE STUDIOS™** website from the Figma design (`node-id=1-41`) built with **React**, **Vite**, **JavaScript**, and **CSS Modules**.

## Design Specifications

- **Canvas Frame**: `1440px` width × `4738px` height
- **Background**: `#000000` (Pure Black)
- **Primary Typography**: `Beausite Classic` (Bold, Semibold, Medium, Regular)
- **Design Tokens**:
  - Primary Text: `#FFFFFF`
  - Secondary/Muted: `#747474`, `#797979`, `#878787`
  - Subtle Borders & Dividers: `#363636`
  - Radius: `2px`
- **Grid Layout**: 4-column system (`345px` columns, `12px` gaps, `1416px` max-content width with `12px` side padding)

## Features & Sections

1. **Top Navigation & Dynamic Time**:
   - Compact vector brandmark (`NORQUE™`)
   - Navigation links (`ABOUT`, `WORKS`, `SERVICES`) with smooth scroll
   - Live real-time Egypt GMT clock (`Egypt, HH:MM:SS AM/PM GMT`) updating each second
2. **Hero Section**:
   - Upper manifesto: `"Built for brands that want something real"` & `"Creating Worldwide ©"`
   - Monumental Brand Logo (`NORQUE™`) composed of high-fidelity vector groups
3. **Hero Feature**:
   - `Recent-Works 1` visual showcase with subtle hover interactions
   - Metadata caption with studio credit and copyright
4. **Studio Manifesto**:
   - Editorial multi-column narrative layout
   - Interactive links to Works, Behance, and Email inquiry
5. **Selected Works (04)**:
   - 2×2 curated project grid (`AXIS®`, `Fusion Form®`, `STUDIO JUZėNAS®`, `MMS ARCHITECTS™`)
   - Interactive project preview modal with details and inquiry trigger
6. **Studio Philosophy / Services**:
   - Section 5 typography presentation
7. **What's Happening Now**:
   - 4-card dispatch news grid with authentic imagery and story cards
8. **Footer**:
   - Project inquiry trigger (`"Got a project on mind? Let’s make it alive!"`)
   - Monumental Brand Logo with back-to-top interaction
   - Full navigation links, legal policy triggers (Terms & Privacy), and copyright
9. **Interactive Modals**:
   - Project Details Modal
   - Contact / Project Brief Form with one-click email copy
   - Terms & Conditions and Privacy Policy Dialogs

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
